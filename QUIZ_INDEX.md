## 📋 Sample Questions

### Example: Lesson 1 - Basics of English Grammar

**Multiple Choice**:
```
Which of the following is a complete sentence?
A) Running quickly
B) The cat sat ✓
C) Very beautiful day
D) Without thinking
```

**True/False**:
```
Every complete sentence needs a subject and a verb.
Answer: True
```

**Fill in the Blanks**:
```
Every sentence needs a _____ and a verb.
Answer: subject
```

**Sentence Correction**:
```
She go to the store yesterday.
Correct: She went to the store yesterday.
```

**Short Answer**:
```
What is a subject in a sentence?
Answer: A subject is who or what the sentence is about
```
